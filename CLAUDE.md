# MT5 Exness demo bot

Python MT5 trading bot (Exness demo account). Repo is early-stage; see README.md.

## Token discipline
- Read only the files and line ranges the task needs; use Grep before Read.
- Answer directly; don't restate earlier context or paste whole files.
- One agent by default; no parallel agents unless tasks are independent.
- Make the smallest change that solves the problem; reuse existing code.
- Suggest /clear between unrelated tasks and /compact in long ones.

## Safety
- Demo account only. Never place or enable live trading without explicit user approval.
- Never write broker logins, passwords, or API keys into files or prompts; use env vars and keep them out of git.
- Backtest or run on demo before any strategy change; report failures honestly.
